
# 💗📚 Livraria New Pink

> Um projeto em constante evolução, acompanhando minha jornada no desenvolvimento de software! ✨

## 🌸 Sobre o projeto

A **Livraria New Pink** é um projeto de desenvolvimento web criado para colocar em prática meus conhecimentos em programação, explorar minha criatividade e acompanhar minha evolução durante a faculdade de **Desenvolvimento de Software Multiplataforma na Fatec Diadema**.

A proposta é desenvolver um site de livraria com uma identidade visual delicada, acolhedora e intuitiva, unindo tecnologia, criatividade e minha paixão por projetos com personalidade.

Mais do que criar um site, quero transformar este projeto em um espaço de aprendizado contínuo, aplicando novos conhecimentos e aprimorando minhas habilidades ao longo da minha formação.

## 🎯 Objetivos

- 📚 Desenvolver e aprimorar um site de livraria.
- 💻 Praticar conceitos de desenvolvimento web.
- 🎨 Explorar a criatividade na construção de interfaces.
- 📱 Desenvolver layouts responsivos e intuitivos.
- 🧠 Aplicar os conhecimentos adquiridos na faculdade.
- 🚀 Experimentar novas tecnologias e funcionalidades.
- 🌱 Registrar minha evolução como desenvolvedora.
